# LongCat Agent 工作台 · 交互 Demo

在保留 LongCat 原有品牌语言（白底、浅灰侧栏、LongCat 绿色、官方 logo 与 `LongCat，Beyond Scale`）的基础上，把原来的 playground 式对话页升级成 Agent 驱动的工作台。

## 预览

- **单文件成品**：`LongCat-Agent-Demo.html`（CSS / JS 已内联，可直接分享、双击打开）
- **源码版**：`index.html` + `styles.css` + `app.js`

无构建步骤、无外部依赖。

也可以在当前工作区启动静态预览：

```bash
cd longcat-agent
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765/>。

视觉预览见 `previews/` 文件夹。

## 保留的 LongCat 原有功能

- 左侧历史对话、今天 / 7天内 / 30天内 / 2026-09 分组
- 开启新对话、侧边栏收起
- 深度思考、联网搜索（已改为智选模式自动路由，见下）
- 图片生成、视频生成、深度研究（收进「智选模式 / Smart Mode」菜单，同时支持意图自动路由）
- 附件上传、语音输入、发送
- 加入我们、API 开放平台
- 用户账户区域、AI 生成提示与备案号

## 新增的 Agent 工作台能力

- **Claude 式输入区布局**：模型与思考强度位于输入框外右下角，按钮无边框；智选模式（Smart Mode）紧挨输入框内的附件按钮
- **语言切换**：左下角账户弹层提供「中文 / English」，切换后 Smart Mode 状态在「智选模式」与「Smart Mode」之间切换
- **官方 Logo**：使用提供的 LongCat 标准 logo（PNG，透明底），同步用于页头、Agent 头像、加入我们、浏览器预览与 favicon
- **思考强度**：自动 / 快速 / 深入，只控制思考深度，不再包含搜索描述
- **搜索能力**：在「智选模式 / Smart Mode」菜单内提供自动 / 总是打开 / 总是关闭三种策略
- **深度研究约束**：选择深度研究后，联网搜索强制开启并锁定，思考强度默认切换为「深入」；离开深度研究后恢复原有搜索设置
- **本地生活 / Local Life**：强制开启联网搜索，思考强度锁定为最高；支持中英文模式名称随账户语言切换
- **演示产出闭环**：生图/生视频返回带「仅做demo展示」的占位结果；深度研究提供可打开的 HTML 演示报告；所有模式均可发送、运行、停止和重新生成
- **计划确认**：运行详情内可关闭「允许 Agent 自动执行」，关闭后新任务先进入计划待确认，可批准或调整
- **本地生活推荐 Lab**：选中本地生活后，输入框下方展示「吃喝玩乐推荐」与附近好店、吃点什么、闪购好物、舒适住宿四个可点击灵感卡片
- **图片生成参数**：图片生成模式下以参考图、比例、风格替换搜索配置，参数会带入生成结果
- **图片生成案例**：选中图片生成后，输入框下方展示 8 个可点击的灵感案例，点击即填入示例 prompt；输入框提示同步切换为画面描述引导
- **视频生成参数**：视频生成模式下以参考图、比例、时长替换搜索配置，参数会带入视频生成结果
- **视频生成案例**：选中视频生成后，输入框下方展示 8 个 16:9 灵感案例，点击即填入视频 prompt；输入框提示同步切换为视频画面描述引导
- **生图 / 生视频限制**：选择图片生成或视频生成后，思考强度自动变为「关闭」并禁用；hover 提示「图片生成/视频生成模型不支持思考」，同时任务不会调用搜索或思考
- **智选模式**：图片生成、视频生成、深度研究、本地生活收进「智选模式 / Smart Mode」菜单，同时识别 prompt 意图自动调用
- **无重复控制**：智选模式菜单内不再重复放置「深度思考」入口，避免与外部思考强度冲突
- **能力外显**：选择智选模式时，能力框显示「智选模式 / Smart Mode」；指定图片 / 视频 / 深度研究 / 本地生活后，能力框同步显示对应意图
- **按模式展示灵感**：默认不展示额外推荐；图片/视频/本地生活模式只在对应模式下展示案例或推荐 Lab，切换后自动隐藏
- **任务计划与执行时间线**：拆解、检索、验证、生成交付物，支持停止与重新生成
- **运行详情抽屉**：执行计划、工具调用、权限开关、运行统计
- **项目与产出物**：统一管理上下文和可编辑交付物
- **二期工作区导航**：项目行新增「+」新建项目入口，新增「自定义」入口并标记「二期」；「开启新对话」承接 Claude 的「新建」
- **结果形态**：深度研究报告、数据图表、幻灯片、可运行原型、图片方案、视频预览
- **Claude 式动作**：分享、复制、导出、继续追问、局部操作
- **响应式**：桌面侧栏、移动端侧栏抽屉、思考强度与能力菜单均可完整访问
- **模型分组**：文本模型 LongCat-2.0 / LongCat-2.5-Preview / LongCat-2.5；多模态模型 LongCat-Image / LongCat-Video
- **模型与模式绑定**：图片生成 ↔ LongCat-Image，视频生成 ↔ LongCat-Video；选择图片/视频模型会自动进入对应模式，选择文本模型会退出媒体模式并恢复原文本模型
- **Agent 运行**：默认自动编排；思考、搜索与垂直能力由统一的智选策略决定

## 说明

这是一个高保真前端交互原型。Agent 执行、检索结果、行情/销售数据与生成内容均为演示数据，不连接真实模型或业务后端；导出按钮会实际下载 Markdown / CSV / HTML 演示文件。

智选模式目前由前端启发式规则模拟：时间敏感、研究类问题会触发联网搜索；复杂任务会触发深度思考；包含海报/短片/调研等意图的 prompt 会自动切换到对应垂直能力。
